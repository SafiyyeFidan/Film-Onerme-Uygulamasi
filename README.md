# 🎬 Film Önerme Uygulaması

## 🛠️ Kullanılan Teknolojiler
* **Geliştirme Ortamı:** C# Windows Forms (.NET)
* **Veritabanı:** MS SQL Server
* **Versiyon Kontrol:** Git & GitHub
