# 🎬 Film Önerme Uygulaması

Bu proje, kullanıcıların tercihlerine ve türlerine göre film önerileri sunan, C# Windows Forms ile geliştirilmiş bir masaüstü uygulamasıdır.

## 🛠️ Kullanılan Teknolojiler
* **Geliştirme Ortamı:** C# Windows Forms (.NET)
* **Veritabanı:** MS SQL Server
* **Versiyon Kontrol:** Git & GitHub
